# Visual assets — provenance

Every image on the site comes from the two design references supplied by the
family (`docs/reference/`) or is drawn in code. Nothing is downloaded from stock
libraries and nothing is generated by an AI model inside this project.

## Royal intro (`public/intro/`)

| Files | How they were made |
| --- | --- |
| `backdrop`, `door-left`, `door-right`, `frame-left`, `frame-right`, `props-left`, `props-right`, `foreground-left`, `foreground-right`, `envelope-pocket`, `envelope-flap`, `seal-top` | Cut from **Reference A** (`reference-a-royal-intro.jpg`, 864 × 1536) by `tools/intro/build_intro_assets.py`: hand-placed polygons, GrabCut for the brass lamp stands, feathered masks through plain floor. |
| painted-in areas (garden beyond the doors, steps behind the envelope, floor behind the foreground lamps, door bottoms, the floor under the removed "Tap to open" button) | Deterministic fills derived from neighbouring pixels of the same painting (mirroring, row-sampled marble bands, OpenCV inpainting for thin lettering). |
| `envelope-inside`, `envelope-lining` | Velvet fills generated by the same script (noise + light falloff), with gold piping traced along the flap edge. |

Each layer is exported at 1× (864-wide stage) and 2× (1.5 × scale, Lanczos +
light unsharp mask) as WebP; the browser picks one via `srcset`. Layer positions
are written to `src/components/intro/sceneManifest.json`.

Regenerate: `python tools/intro/build_intro_assets.py --preview` (needs Python 3
with `opencv-python`, `numpy`, `pillow`). Previews go to `tools/out/` (ignored).

The intro's lettering ("A ROYAL INVITATION", the names, the date) and the
"Tap to open" cartouche are live HTML / SVG drawn after Reference A — the painted
lettering was removed from the image so the text stays crisp, accessible and
translatable.
